# NeurIPS 4-page report

## Compile

1. Download `neurips_2024.sty` from https://neurips.cc/Conferences/2024/CallForPapers
   and place it next to `paper.tex`.
2. Install a LaTeX distribution (e.g. TeX Live / MiKTeX on Windows, or Overleaf online).
3. Run:
   ```bash
   pdflatex paper.tex
   pdflatex paper.tex      # second pass for references
   ```
   Output: `paper.pdf`.

## Figures to include

Generated by `scripts/explain_shap.py` into `reports/figures/`:

- `shap_summary_revenue.png` — beeswarm of top-20 features
- `shap_bar_revenue.png` — mean |SHAP| per feature
- `prophet_components_revenue.png` — trend / weekly / yearly / holiday decomposition
- Same four files for COGS

Add them inside the paper body with `\includegraphics` if page budget allows
(currently the text alone is ~3.5 pages, leaving room for one or two figures).

## Style

Uses the official NeurIPS 2024 `\usepackage[final]{neurips_2024}` setting (non-anonymous).
Swap to `\usepackage{neurips_2024}` if the submission form requires the
anonymized version.
